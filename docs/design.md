# 界面与本地适配

交互参考 Claude Projects：持续主对话、右侧 Threads / Library、由模型安排线程、项目共享记忆。代码与运行时基于 DeepSeek Harness。

| 部分 | 实现 |
| --- | --- |
| 项目入口 | DSH 原生侧栏项目列表；创建时选择本机目录 |
| 主对话 | 沟通、调度、汇总；不提供终端、文件编辑或待办工具 |
| 线程 | 通用助手，能讨论、研究和操作；使用原生极简模板所需能力 |
| 会话 UI | 复用 DSH 原生 conversation.content、输入框、模型和权限控件 |
| 显示模式 | 简洁模式展示文字、成果、待办、提问、审批和线程通信；全部展示保留原始过程 |
| 线程操作 | 点击标题进入；左侧圆圈多选后批量结项／重开；运行提示仅代表本地执行 |
| 设置 | 点击项目名称打开 General / Memory / Usage |
| Library | 文件夹视图、本机引用、导入文件、链接和成果 |
| 主题 | 跟随 DSH 深浅色，蓝色强调色；两侧宽度可拖动 |

普通侧栏隐藏已归属项目的会话，不通过归档实现隐藏。删除与归档分别处理；删除项目需要确认，保留用户的工作目录和引用文件。

项目壳位于 Shadow DOM，原生会话通过 slot 保留在 light DOM。简洁模式只修改展示，不改写会话日志或产生新的模型消息。线程通信和已提交的问题选择使用原生事件投影；刷新后可从日志恢复。

针对 DSH 0.2.1-rc.3 的语义 DOM 适配集中在 `src/conversation-display.css` 和 `src/client.jsx`。宿主升级时应重新验收消息显示、输入框、审批、线程跳转与侧栏隐藏。
